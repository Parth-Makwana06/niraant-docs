## 🌟 What is Niraant?
Niraant is a personal organizer and secure digital vault designed specifically for Indian households. It helps you safely store critical documents, manage credentials, and set reminders for bill due dates—all with offline-first security and local data encryption.

---

## ✨ Key Features

- **📂 Smart Document Vault**: Securely scan, upload, and categorize your utility bills, warranty cards, and home documents.
- **🔍 On-Device OCR**: Automatic text recognition from images using Google ML Kit. All processing happens locally on your device to protect your privacy.
- **⏰ Smart Reminder System**: Set tasks and alarms. If a reminder goes unacknowledged, it auto-snoozes and alerts you hourly until marked complete.
- **📅 Document Expiry Alerts**: Dynamic notifications sent 30, 15, 7, and 1 day before any document or warranty expires.
- **🔐 Credentials Manager**: Safe and encrypted local password vault to store credentials securely.
- **🔒 App Lock Security**: Built-in biometric/PIN protection layer to keep your personal data confidential.
